> Full-stack marketplace application - from MVP to enterprise architecture

## 🎯 Project Goal

Build a production-ready marketplace (OLX-like) demonstrating:

- Full-stack development (React → Next.js + Spring Boot)
- Microservices architecture
- Event-driven design (Kafka, RabbitMQ)
- Cloud deployment (AWS + Kubernetes)
- DevOps practices (CI/CD, monitoring)
- AI integration (semantic search, recommendations)

## 📊 Tech Stack

### Frontend

- React → Next.js 15
- TypeScript
- Tailwind CSS + shadcn/ui
- React Query

### Backend

- Java 17+
- Spring Boot 3.x
- PostgreSQL + MongoDB + Redis
- Kafka + RabbitMQ

### DevOps

- Docker + Kubernetes
- AWS (ECS, RDS, S3, CloudFront)
- GitHub Actions
- Terraform

### Observability

- ELK Stack (logs)
- Prometheus + Grafana (metrics)
- Jaeger (tracing)
